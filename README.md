# Dofus Zaap (`/zaap`) — Plugin Stream Deck & Soomfon (StreamDock)

Plugin contenant **les 45 Zaaps officiels de Dofus 3 (Unity)** avec leur nom, leur région colorée et leurs coordonnées `[X, Y]`.

Compatible avec :
- **Elgato Stream Deck** (Mini 6 touches, MK.2 15 touches, XL 32 touches, Stream Deck +, Mobile)
- **Soomfon Stream Controller SE / HotSpot StreamDock / Mirabox / Ajazz**

---

## Fonctionnalités

1. **Bouton unique `Zaap` avec liste déroulante des 45 Zaaps**
   - Glissez le bouton **Zaap** sur votre Stream Deck et choisissez le Zaap souhaité dans la liste déroulante classée par région.
   - Le bouton met automatiquement à jour son icône avec :
     - Le bandeau de couleur de la **Région** en haut (`ASTRUB`, `AMAKNA`, `CANIA`, `FRIGOST`, `INCARNAM`, etc.)
     - Le **Nom du Zaap** au centre
     - Les **Coordonnées `[X, Y]`** en bas

2. **Combinaison en jeu adaptée à Dofus 3 (Unity)**
   - **Par défaut** : `Espace + /zaap x,y + Entrée` (avec ScanCodes matériels pour ouvrir automatiquement le chat Dofus 3, coller la commande `/zaap x,y` et valider).
   - **Alternatives** : `Entrée + /zaap x,y + Entrée` ou copie simple dans le presse-papier.

3. **Ciblage Monocompte (Fenêtre active uniquement)**
   - Envoie la commande uniquement sur la fenêtre `Dofus.exe` actuellement utilisée (ou copie simple dans le presse-papier), sans enchaînement automatisé multicompte.

---

## Installation

1. Double-cliquez sur **`INSTALLER.bat`** (ou exécutez `install-plugin.ps1` avec PowerShell).
2. Redémarrez votre logiciel **Elgato Stream Deck** ou **Soomfon (StreamDock)**.
3. Vous trouverez également les archives prêtes à partager dans le dossier [`Partage/`](./Partage).
